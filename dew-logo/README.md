# DEW — D Logo Exploration

Six original monochrome marks based on soft dots, capsules, rounded corners, and generous negative space.

Assumption: DEW is a modern digital-product / creative-technology brand; the identity should feel professional, friendly, modular, and native to screens.

1. **Continuum** — a single calm gesture; dependable and highly legible.
2. **Droplet Chain** — fluid modules plus a satellite droplet; friendly and expressive.
3. **Soft Cut** — confident solid silhouette with a rounded counter; strongest at tiny sizes.
4. **Orbit** — a precise frame with an independent node; suggests systems and possibility.
5. **Modular** — assembled tiles suggest components, teams, and adaptable software.
6. **Dewpoint** — a compact D with an inner dew node; distinctive and ownable.

All SVGs use `viewBox="0 0 100 100"` and `currentColor`, so they inherit any CSS/text color.
